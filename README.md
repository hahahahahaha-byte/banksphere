# BankSphere - Enterprise Banking Management System

A role-based digital banking platform built with React, Redux Toolkit, and Firebase.

## Features
- **Customer**: View balance, transactions, loans, submit requests
- **Employee**: Manage customers, approve loans ≤ 1M, process transactions
- **Manager**: Full system access, manage employees, approve high-value loans

## Tech Stack
- React.js
- Redux Toolkit
- Firebase (Auth + Firestore)
- React Bootstrap
- JSON Server

## Installation
1. Clone the repository
2. Run `npm install`
3. Add `.env` file with Firebase config
4. Run `npm run dev` to start

## Default Ports
- React: http://localhost:3000
- JSON Server: http://localhost:5000# banksphere
